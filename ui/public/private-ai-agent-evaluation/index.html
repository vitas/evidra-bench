What Stays Confidential

A private evaluation can keep customer infrastructure names, transcripts, tool payloads, proprietary prompts, incident patterns, and vendor notes out of public pages. The public method still matters: the evaluator should explain the scenario slice, scoring rules, verifier standards, and unsafe-pass taxonomy well enough for the customer to trust the report without exposing sensitive material.

If a customer later wants a public proof point, Evidra Bench can publish a sponsored public report with sanitized data and clear labeling. The sponsor should not control scoring or findings.
