# Code Of Conduct

This project is for practical, evidence-based work on infrastructure-agent
evaluation. Keep discussion technical, respectful, and focused on improving the
software and scenario corpus.

Expected behavior:

- Be direct without being abusive.
- Assume public discussions may be read by future contributors.
- Critique code, claims, and trade-offs rather than people.
- Respect private reports, customer data, and security-sensitive details.

Unacceptable behavior includes harassment, targeted insults, discriminatory
remarks, intimidation, and publishing private information without consent.

If you need to report a conduct or safety issue, contact the maintainers
privately through GitHub. Do not include private security details in a public
issue.
