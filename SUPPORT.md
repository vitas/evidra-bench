# Support

Use GitHub issues for reproducible bugs, documentation problems, and public
scenario proposals.

For a useful bug report, include:

- Bench version or commit
- operating system
- Kubernetes runtime (`kind`, `k3d`, or other)
- scenario id
- command used
- relevant logs or sanitized artifacts

Do not attach private transcripts, API keys, customer incident data, or hosted
report artifacts to public issues.

Commercial private benchmark work, sponsored public runs, and custom scenario
packs are handled through the product site: `https://bench.evidra.cc`.
